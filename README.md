# 网站恢复助手 (Site Revival)

Chrome / Edge 浏览器扩展（Manifest V3）：**网页打不开时，自动保存网址和你在页面上填写的表单内容；等网站恢复后自动重新访问，并把表单内容填回去。**

据说可以精准抓住github在国内恢复访问的那一刹那~

## 功能

- 自动检测网页加载失败（超时、连接被拒、DNS 解析失败等网络类错误）
- 你在网页里输入的内容自动暂存为本地草稿（边输入边保存，提交瞬间也会立即保存一次）
- 后台定时探测网站是否恢复（默认每 5 分钟；检查间隔可自由输入：1–1440 分钟，或 10–60 秒）
- 恢复后自动重新打开原网页：优先复用原来那个打不开的标签页（reload），否则新开一个后台标签页
- 自动还原表单内容，页面右下角提示"已还原 N 个字段"
- 工具栏角标显示待恢复数量；弹窗里可查看、手动打开或删除记录
- 桌面通知提醒（可关闭）

## 安装（开发者模式加载）

1. 打开 Chrome（或 Edge），地址栏访问 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 打开右上角（Edge 为左侧）的「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本文件夹 `site-revival-extension`
4. 建议在工具栏把扩展图标固定住，方便看角标和打开弹窗

## 使用方法

平时无需任何操作。当某个网页打不开时：

1. 扩展图标出现红色数字角标，点开弹窗可以看到失效的网址、错误原因和失效时间
2. 之后你正常上网即可，扩展会在后台每隔一段时间探测该网站
3. 网站恢复后：自动重新打开该网页，并把之前填写的表单内容填回去，页面右下角会出现提示
4. 确认内容无误后，**由你自己点击提交**
5. 不想等自动检查？在弹窗里点「立即检查」，或直接点某条记录的「打开」

## 数据持久化与浏览器重启

- 检查间隔、待恢复列表和表单草稿都保存在本机 `chrome.storage.local`，**重启浏览器后自动恢复**，无需任何操作
- 浏览器每次启动后约 15 秒，扩展会自动先做一轮检查，尽快探测之前打不开的网页是否已恢复
- 工具栏角标会在启动时恢复显示待恢复数量

## 隐私与安全设计

- 所有数据只存在本机浏览器的 `chrome.storage.local`，**不上传任何服务器**
- 密码框、文件选择框、隐藏字段一律不保存
- 表单恢复后**不会自动提交**——自动提交可能导致重复下单、重复发帖等严重后果，因此填回后由你人工确认
- 草稿保留 7 天，过期自动清理；对应的恢复记录被删除时草稿一并删除

## 工作原理

| 文件 | 职责 |
| --- | --- |
| `background.js` | 监听 `webNavigation.onErrorOccurred` 捕获主框架加载失败（仅网络类错误）；用 `alarms` 定时对待恢复网址发 HEAD/GET 探测（HTTP 状态码 < 500 视为已恢复）；恢复后 reload 原标签页或新开标签页 |
| `content.js` | 监听全页 `input/change/submit` 事件，防抖 700ms 把字段值序列化存入本地草稿；页面加载时向后台查询是否存在待恢复记录，命中则自动还原字段（用原生 setter 赋值并派发事件，兼容 React / Vue 等框架） |
| `popup.html/js/css` | 待恢复列表（打开 / 删除）、立即检查、设置项 |

## 打包与分发

- **目录版**（开发者模式加载）：在 `chrome://extensions` 选择 `site-revival-extension` 文件夹
- **CRX 包**：`../site-revival-extension.crx`，由私钥 `../site-revival-extension.pem` 签名
  - **请妥善保管 .pem 私钥**：使用同一把私钥打包才能保持相同的扩展 ID，发布更新版本时必须使用它
  - 注意：现代 Chrome 出于安全考虑**不允许直接双击/拖拽安装 CRX**，需通过企业策略（`ExtensionInstallSources` 白名单 + 托管安装）或组策略 `ExtensionInstallForcelist` 部署；个人使用建议继续用开发者模式加载目录

## 注意事项

- 需要登录的网站，恢复后要先重新登录才能看到还原的表单（密码未保存）
- 浏览器对扩展定时器有最低频率限制：设置 10–29 秒的间隔时，正式安装的扩展实际生效可能被浏览器强制为约 30 秒；开发模式（加载已解压）下更宽松
- 已永久失效的网站会一直留在列表里，请在弹窗中手动「删除」
- 扩展更新或浏览器重启后，定时探测会自动重建
- 测试方法：打开任意带表单的网页 → 填写内容 → 断网后刷新该页面（加载失败被记录）→ 恢复网络 → 在弹窗点「立即检查」或等待下一个检查周期 → 页面自动重开且内容被填回
